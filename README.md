# 看圖識詞 · 互動學習教室

一個用視覺 AI 幫你看圖學英文的互動學習工具！上傳照片，AI 自動標出圖片中的 10 個單字，並提供例句、音標、中文翻譯和文法拆解。

## ✨ 功能特色

### 🎯 七大學習模組
1. **實景熱點** - 照片上直接標註單字（紅色粗體 + 音標），圖片等比縮放、完整顯示不被擠壓
2. **圖片句子** - 這張圖的完整描述句＋文法拆解，可整段朗讀
3. **單字圖卡** - 每個單字的完整學習卡片，內建兩顆「連續播放」喇叭
4. **翻卡複習** - Flashcard 式記憶練習（正面就有單字＋音標）
5. **隨堂小測** - 選擇題／輸入單字雙模式，每個單字一題
6. **常用語塊** - 108 課綱 A2–B1 常考片語／介系詞組／高頻搭配（147 條）
7. **學習檢核** - 一鍵跑完整流程的自我檢查（20 項）

### 🖼️ 實景熱點的版面
- 圖片用 `object-fit: contain` 等比縮放，**永遠完整落在可用區域內**，不會被右側（或手機下方）的辨識設定面板擋住
- 視窗縮放、切回分頁都會重新計算一次，長邊不會超出
- **辨識設定可收合**：按側欄右上「收合 ⟩」把整個設定面板收起來，圖片立刻吃滿全部寬度（狀態會記住，下次開啟沿用）；要調模型或 API Key 時按右上角浮動的「⚙️ 辨識設定」再展開
- 句子與文法拆解移到獨立的「💬 圖片句子」分頁，實景熱點只留標註與編輯工具，畫面更乾淨

### 🔊 連續播放（單字圖卡）
- **🔊 單字＋基礎例句**：依序唸「單字 → 基礎例句 → 下一個單字…」，播放中的卡片會亮綠框並自動捲到視線內
- **🔊 單字＋進階例句**：同樣流程，換成進階例句
- 播放中按鈕變成「⏸ 停止播放」，另有獨立的 ⏹ 停止鈕；切到別的分頁、換圖片、或點任一單字發音都會自動停止
- 用 `onend` 串接，是真的等一句念完才念下一句（不是固定延遲）

### ✏️ 隨堂小測的兩種模式
| 模式 | 題目 | 作答方式 |
|---|---|---|
| 📋 選擇題（預設） | 「apple」的中文意思是？／「蘋果」的英文是？ | 點選項 → **還能改選** → 按「確認送出」才判定 |
| ⌨️ 輸入單字 | 請輸入「蘋果」的英文單字 | 打字後按 Enter 或「確認送出」；大小寫、前後空白、標點都會自動容錯 |

- 送出前可以任意改選，只有最後選的那個會被判定（不會像以前一樣點一次就鎖死）
- 送出後顯示正確答案、音標與中文，按「下一題」繼續；模式會記住，下次開啟沿用

### 📚 每個單字包含
- 英文單字 + IPA 音標
- 中文翻譯（繁體中文）
- 📗 **基礎版例句**（A2，6–10 字，基礎句型）
- 📘 **進階版例句**（B1，10–16 字，進階句型）
- 🧩 例句中命中的常用語塊標籤
- 點擊英文直接發音（en-US TTS）

### 🧠 內建 A2–B1 句庫（不連網也能用）
- 24 組基礎句型 + 23 組進階句型，每句自動輪替、不重複
- 298 個核心名詞（含分類與中文量詞），每個字都能產出合格的基礎＋進階例句
- 147 條常用語塊（動詞片語／介系詞片語／高頻搭配／句型語塊）
- 模型例句若出現 `in the picture`、缺字或重複，會自動改寫成句庫版本

### 🤖 雙模型支援
- **Groq 雲端（優先）** - 速度快，預設第一順位
- **DeepSeek Flash（自動接手）** - Groq 429／逾時／金鑰失效時直接接手，不打斷流程
- **本地 Ollama** - 隱私安全，完全離線（墊底備援）
- 任何錯誤都**不彈出 alert**：只在底部顯示 toast、右側顯示可關閉的提示卡，App 可繼續操作

接手順序（右側面板會即時顯示）：
`目前選的模型 → 其他 Groq 模型 → DeepSeek Flash → 本機 Ollama`

- 遇到 429 會讓該模型冷卻 45 秒，後續請求直接走備援，不會每句都重撞一次
- 全部模型都失敗時：辨識會顯示「重試辨識」提示卡；例句則自動改用內建 108 課綱句庫

### 📱 手機友好
- 響應式設計，手機瀏覽器完美顯示
- **內建相機直接以 720p 取景**：不落地 12MP 大檔，拍完就是 100–200KB 的 JPEG
- 從相簿選圖也會自動壓縮：長邊 1280、100–200KB、EXIF 方向自動校正
- 大按鈕適合觸控操作

### 🖼️ 影像管線（為什麼不會爆記憶體）
手機後置鏡頭一張 12MP 照片，解碼後約佔 48MB RAM，轉成 base64 再翻一倍——直接丟給 VLLM 很容易 OOM 或逾時。這裡的做法：

```
拍照/選圖 → createImageBitmap 解碼（EXIF 自動轉正、背景執行緒）
          → canvas 縮到長邊 1280（720p）
          → JPEG 反覆試品質，鎖定 100–200KB
          → 只保留 Blob，全程不產生巨型 base64
          → VLLM 另存一份 1024 長邊、≤180KB 的縮圖（載入時建一次，後續重用）
```

- 若品質降到 0.55 仍超過 200KB，會自動縮小尺寸再試（保留清晰度優於硬壓品質）
- 連續呼叫辨識／造句／驗證時共用同一份縮圖快取，不重複編碼
- 對外可直接用 `resizeImageForVllm(file, 1280, 0.85)` 取得壓好的 `File`

## 🚀 快速開始

### 方式一：直接打開
直接雙擊 `看圖識詞標註器.html` 即可在瀏覽器中打開！

### 方式二：本地 Ollama（推薦）
1. 安裝 [Ollama](https://ollama.com/)
2. 下載模型：
   ```bash
   ollama pull qwen3.5:4b
   ollama pull qwen2.5:7b
   ```
3. 設定跨域：
   ```bash
   set OLLAMA_ORIGINS=*
   ollama serve
   ```
4. 打開 `看圖識詞標註器.html`

### 方式三：Groq 雲端模型
1. 去 [Groq Console](https://console.groq.com/) 申請免費 API Key
2. 在頁面側邊欄貼上 API Key
3. 選擇 Groq 模型即可

## 📋 使用說明

1. **上傳圖片** - 點擊「選擇圖片」或「拍照」
2. **自動辨識** - 點擊「自動辨識」按鈕
3. **學習單字** - 切換上方分頁查看不同學習模組
4. **點擊發音** - 點擊任何英文單字或例句就會朗讀
